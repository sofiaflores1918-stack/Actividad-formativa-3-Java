# Agregar herencia en Java-Actividad_3
Aplicación desarrollada en Java para practicar la herencia, utilizando una clase base y clases derivadas.

¿Qué contiene?

•⁠ ⁠Clase base Estudiante. •⁠ ⁠Clases derivadas EstudiantePresencial y EstudianteEnLinea. •⁠ ⁠Reutilización de atributos y métodos. •⁠ ⁠Uso de extends, super() y @Override. •⁠ ⁠Registro, búsqueda y consulta de estudiantes.

Objetivo

Aplicar la herencia en Java para reutilizar código y agregar características propias a cada clase derivada.
